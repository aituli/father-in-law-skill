# 基础信息录入脚本

## 开场白

```
我来帮你创建这位老丈人的 Skill。只需要回答 3 个问题，每个都可以跳过。
```

---

## 问题序列

### Q1：称呼/代号

```
这位老丈人怎么称呼？（姓氏、昵称或代号都行，多个字用 - 连接）

例：zhang-shifu 或 老王
```

- 接受任意字符串
- 生成的 slug 统一用 `-` 连接（不用下划线）
- 中文自动转拼音再用 `-` 连接（"张师傅" → `zhang-shifu`）
- 英文直接小写 `-` 连接（"Uncle Wang" → `uncle-wang`）

---

### Q2：基本信息

把年龄、职业、居住地、家庭结构放在一个问题里，让用户一句话说完：

```
用一句话描述他的基本信息——年龄、职业、居住地、家庭结构，想到什么写什么，跳过也行。

例：65岁退休教师，住杭州，和女儿女婿同住
     58岁企业老板，住深圳，周末才见面
```

从用户的回答中解析以下字段（缺失的留空）：
- **年龄**：数字或年龄段（如"60多"）
- **职业**：退休前/现在的职业
- **居住地**：城市或"同城/异地"
- **家庭结构**：是否同住、见面频率

#### 10种老丈人类型参考

| 类型 | 典型特征 | 如何识别 |
|------|---------|---------|
| 传统威严型 | 家长权威、不善表达关爱、重面子 | 话不多但很有分量，让你有点怕 |
| 幽默风趣型 | 爱开玩笑、自来熟、没架子 | 第一次见面就能聊，爱调侃你 |
| 沉默寡言型 | 话少、内敛、观察型 | 饭桌上听得多说得少，难猜心思 |
| 酒桌话痨型 | 酒后吐真言、情感外露 | 平时话少，三杯下肚变话痨 |
| 知识分子型 | 高学历、理性、爱讲道理 | 聊天偏文化历史，喜欢"教育"你 |
| 经商精明型 | 精明、务实、利益导向 | 喜欢谈赚钱、试探你的"条件" |
| 退休干部型 | 官架子、讲规矩、爱说教 | 说话有"领导腔"，关心时事 |
| 农村朴实型 | 朴实、勤劳、不善言辞 | 默默付出，不看重物质条件 |
| 挑剔苛刻型 | 完美主义、难取悦、比较型 | 总有不满意，拿你和别人比 |
| 开明现代型 | 思想开放、尊重隐私、平等 | 像朋友一样相处，不干涉 |

### Q3：性格画像

把老丈人类型、MBTI、个性标签、主观印象全部合在一起，让用户自由描述：

```
用一句话描述他的性格——老丈人类型、MBTI、个性特点、你对他的印象，
想到什么写什么，跳过也行。

例：传统威严型，话少但威严，爱喝白酒，对我还不太满意
     幽默风趣型，ENFP，自来熟，第一次见面就拉着我喝酒
```

从用户的回答中识别并提取以下字段（缺失的留空）：
- **老丈人类型**：从上述10种类型中匹配
- **MBTI**：16 种标准类型
- **个性标签**：从下方标签库匹配，也接受自定义描述
- **主观印象**：无法归类的自由描述，直接保留原文

#### 个性标签库

**家庭角色**：
- 家长权威型 / 朋友平等型 / 甩手掌柜型 / 操心过度型

**互动风格**：
- 威严距离感 / 亲和随和 / 阴阳怪气 / 话少观察 / 酒桌兄弟

**情感表达**：
- 不善言辞（默默付出型） / 直接表达 / 借酒抒情 / 从不表扬

**对女婿态度**：
- 考察期 / 已认可 / 不太满意 / 挑剔比较 / 完全信任

**生活习惯**：
- 规律养生 / 爱喝酒 / 爱社交 / 宅家型 / 爱旅游

## 确认汇总

收集完毕后展示：

```
信息汇总：

  👤  {称呼}
  🎂  {年龄}岁，{职业}（若未填则省略）
  🏠  {居住地}，{家庭结构}（若未填则省略）
  🏷️  类型：{老丈人类型}（若未填则省略）
  🧠  {MBTI}（若未填则省略）
  🏷️  个性：{标签列表}（若未填则省略）
  💬  印象：{印象文本}（若未填则省略）

确认无误？（确认 / 修改 [字段名]）
```

用户确认后进入 Step 2 文件导入。
