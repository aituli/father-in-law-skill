# 关系模式分析 Prompt

## 任务

你将收到：
1. 用户手动填写的基础信息（称呼、年龄职业、老丈人类型、个性标签、主观印象）
2. 原材料（聊天记录、家庭群消息、邮件等）

从中提取 **{name}** 的家庭角色与关系模式，用于构建 Relationship Skill。

**优先级规则：手动标签 > 文件分析。有冲突时以手动标签为准，并在输出中注明。**

---

## 提取维度

### 1. 家庭角色定位

分析他在家庭中的位置和角色：

**权威地位**
- 他在家庭中的决策权大小（大事谁说了算）
- 对其他家庭成员（妻子、女儿、你）的态度差异
- 传统家长权威 vs 现代平等观念

**角色表现**
- 作为父亲：对女儿的关心方式（保护型/放手型/干涉型）
- 作为丈夫：与妻子（岳母）的互动模式
- 作为长辈：对你的定位（"考验中的女婿"/"半个儿子"/"外人"）

```
输出格式：
家庭地位：[描述]
对女儿：[关心方式 + 保护程度]
对女婿定位：[他对你的身份认知]
```

---

### 2. 关系互动模式

分析你与他的互动特点：

**接触场景**
- 主要互动场景（酒桌/家庭聚餐/单独相处/几乎不见面）
- 见面频率和时长
- 互动发起方（他主动/你主动/被动见面）

**沟通特点**
- 话题范围（工作/生活/时事/家庭/孩子）
- 沟通深度（表面寒暄/可聊心事/只是应付）
- 信息流向（他说你听/有来有往/都不说）

**权力动态**
- 谁掌握主动权
- 是否需要"讨好"他
- 关系中的压力来源

```
输出格式：
主要场景：[场景描述]
沟通特点：[描述]
关系动态：[谁在主动 + 压力来源]
```

---

### 3. 家庭规则与边界

**显性规则**（明确说出来的）
- 他对女婿的明确要求（如节日必须回家、要对女儿好等）
- 家庭传统（如过年回谁家、节日送礼规矩）

**隐性规则**（未明说但需要遵守）
- 不能触碰的话题
- 需要避讳的事情
- 礼尚往来的默契

**边界感**
- 他对你们小家庭生活的介入程度
- 公私分明的程度
- 尊重隐私的程度

```
输出格式：
显性规则：[列表]
隐性规则：[列表]
介入程度：[高/中/低 + 具体表现]
```

---

### 4. 情感表达方式

**表达习惯**
- 如何表达关心（语言/行动/物质/不表达）
- 如何表达不满（直接说/暗示/沉默/通过女儿传话）
- 如何表达认可（表扬/默认/对外炫耀/送你东西）

**情感触发点**
- 什么情况下他会开心/满意
- 什么情况下他会生气/失望
- 什么情况下他会感动

**对你的特殊态度**
- 与其他女婿/亲戚相比，对你是否有特殊对待
- 是否在某些方面"双标"

```
输出格式：
关心方式：[方式 + 示例]
不满表达：[方式 + 示例]
认可信号：[信号 + 示例]
情感触发：[开心触发/生气触发/感动触发]
```

## 标签翻译规则

将用户填写的标签翻译为具体行为规则：

### 老丈人类型标签

| 标签 | 行为规则（直接写入 relationship） |
|------|----------------------------------|
| **传统威严型** | 家庭大事需要请示他；重要场合要主动敬酒/问候；不能公开反驳他的观点；需要通过"考验"才能获得认可 |
| **幽默风趣型** | 可以用玩笑化解尴尬；可以适度互怼增进感情；陪他喝酒看球是最佳互动方式；不要太拘谨 |
| **沉默寡言型** | 接受沉默，不要强行找话题；用行动而非语言证明自己；观察他的小动作来判断态度 |
| **酒桌话痨型** | 酒桌上要豪爽陪他喝；酒后的承诺/真心话要认真对待；第二天不要提酒桌上的尴尬 |
| **知识分子型** | 聊天要有深度；虚心请教做"好学生"；推荐书/艺术品是加分项；避免低俗话题 |
| **经商精明型** | 展现事业心和潜力；不要太"书生气"；礼尚往来，不要只进不出；适当展现你的"价值" |
| **退休干部型** | 尊重他的"领导"身份；陪他聊时事但顺着他的观点；展现你的"稳重"和"正派" |
| **农村朴实型** | 表现朴实勤快（帮忙干活）；不要铺张浪费；用实际行动证明对女儿好 |
| **挑剔苛刻型** | 保持耐心不要对抗；让妻子做调解人；持续用行动证明；适当"示弱"让他有满足感 |
| **开明现代型** | 像朋友一样自然相处；可以分享年轻人的东西；尊重他的独立空间；坦诚沟通 |

### 对女婿态度标签

| 标签 | 行为规则 |
|------|---------|
| **考察期** | 他还在评估你，需要持续表现；不要松懈或得意忘形；注意细节积累印象 |
| **已认可** | 基本接纳你为家庭一员；可以稍微放松但不要越界；维护好现有关系 |
| **不太满意** | 对你有明确不满；需要找出问题点针对性改进；可能需要妻子做中间人 |
| **挑剔比较** | 总拿你和别人对比；不要对抗比较，用实力说话；寻找差异化优势 |
| **完全信任** | 完全接纳你；可以坦诚沟通；但也要珍惜这份信任 |
