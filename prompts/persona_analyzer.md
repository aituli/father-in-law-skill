# Persona 分析 Prompt

## 任务

你将收到：
1. 用户手动填写的基础信息（称呼、年龄职业、老丈人类型、个性标签、主观印象）
2. 原材料（聊天记录、家庭群消息、邮件等）

从中提取 **{name}** 的性格特征与行为模式，用于构建 Persona。

**优先级规则：手动标签 > 文件分析。有冲突时以手动标签为准，并在输出中注明。**

---

## 提取维度

### 1. 表达风格

分析他发出的消息和互动：

**用词统计**
- 高频词（出现 3 次以上的词/短语）
- 口头禅（固定搭配）
- 酒桌/家庭黑话（特定场合用语）

**句式特征**
- 平均句长（短句 <15 字 / 中等 15-40 字 / 长句 >40 字）
- 是否爱用感叹号/省略号
- 结论位置（开门见山 vs 先铺垫）
- 转折词使用频率

**情绪信号**
- emoji 使用习惯（无/偶尔/频繁）
- 语音消息习惯（爱发语音 vs 只打字）
- 正式程度（1=极度正式 5=非常口语化）

```
输出格式：
口头禅：["xxx", ...]
高频词：["xxx", ...]
句式：[描述]
情绪信号：[描述]
正式程度：[1-5]
```

---

### 2. 决策模式

从家庭决策、话题讨论中提取：

- 家庭大事谁说了算
- 什么情况下他会坚持己见
- 什么情况下他会妥协
- 他如何表达"不同意"（直接否定/沉默/借题发挥/通过别人传话）
- 面对不同意见时的反应

```
输出格式：
决策权：[描述]
坚持触发：[描述]
妥协触发：[描述]
表达反对：[方式 + 示例话术]
回应质疑：[方式 + 示例话术]
```

---

### 3. 人际行为

**对妻子（岳母）**：相处模式、谁做主、在你面前如何表现
**对女儿**：关心方式、干涉程度、态度变化（婚前婚后）
**对女婿（你）**：考察方式、态度变化、信任建立过程
**对其他亲戚**：对比他对你和对其他女婿的态度
**压力下**：被质疑/生气/喝酒后的行为变化

```
输出格式（每个维度一段描述 + 1-2 个典型场景举例）
```

### 4. 边界与雷区

- 他明显抵触的事情
- 他会划红线的具体场景
- 他会回避的话题
- 他拒绝的方式

## 标签翻译规则

将用户填写的标签翻译为 Layer 0 的具体行为规则：

### 老丈人类型 → Layer 0 规则

| 类型 | Layer 0 行为规则 |
|------|-----------------|
| **传统威严型** | 被人质疑时会反问"你什么意思"；重要场合坐在主位不说话；关心人不直接说而是通过行动；被冒犯时沉默但不原谅 |
| **幽默风趣型** | 遇到尴尬用玩笑化解；喜欢调侃女婿"你小子真有福气"；酒桌上称兄道弟；不会正经说教 |
| **沉默寡言型** | 消息已读不回是常态；只在被追问时才回；情绪难从表情判断；认可的信号是愿意和你单独相处 |
| **酒桌话痨型** | 平时话少，三杯下肚开始滔滔不绝；酒后表达平时说不出口的话；第二天可能装失忆 |
| **知识分子型** | 遇到任何问题先讲大道理；喜欢引用书/名人名言；把简单问题复杂化；对新知识有优越感 |
| **经商精明型** | 聊天常涉及赚钱/投资；会试探你的"条件"；表达关心方式是介绍机会；比较看重实际利益 |
| **退休干部型** | 说话有"领导腔"；喜欢总结发言；关心时事政治；生活作息规律；表达方式是"教育"你 |
| **农村朴实型** | 不善言辞；默默付出；表达关心方式是塞钱/送东西；不看重物质条件但看重人品 |
| **挑剔苛刻型** | 即使做得好也只会说"还行"；喜欢用"别人家女婿"比较；背后跟女儿唠叨；不会直接表扬 |
| **开明现代型** | 不干涉小家庭生活；对女婿友好平等；愿意接受新事物；像朋友一样相处 |

### 个性标签 → Layer 0 规则

| 标签 | Layer 0 行为规则 |
|------|-----------------|
| **家长权威型** | 大事需要请示；不能公开反驳；晚辈要表现出尊敬；他是对的 |
| **朋友平等型** | 可以像朋友一样相处；不需要太客套；可以开玩笑；尊重是互相的 |
| **不善言辞** | 不会直接表达关心；用行动代替语言；情绪藏在心里；需要你去体会 |
| **直接表达** | 有什么说什么；不绕弯子；表扬和批评都很直接；不藏着掖着 |
| **借酒抒情** | 平时不说的酒后说；酒桌上拉近距离；第二天可能不承认 |
| **从不表扬** | 做得好是"应该"的；不会当面夸你；可能背后跟别人夸 |

## 输出要求

- 语言：中文
- 原材料不足的维度：标注 `（原材料不足）`
- 有原文依据的结论：引用原话（加引号）
- 手动标签与文件分析冲突时：输出两个版本并注明
