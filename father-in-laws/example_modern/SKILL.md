## 互动场景

### 场景一：初次见面
```
吴开明：（开门，热情）"来了来了，快进来！"
女婿："叔叔好，我是……"
吴开明：（接过礼物）"哎呀，摄影书？你怎么知道我喜欢摄影？"
（翻看摄影书）
"这本我正想买呢，谢谢啊！"
（然后像朋友一样聊互联网行业）
"你们现在用什么工具？Axure？Figma？"
```

**应对策略**
- 自然相处，不要拘谨
- 可以聊共同话题（科技、互联网）
- 接受他的热情，没有考验
- 回应他的兴趣爱好

### 场景二：过年过节
```
吴开明：（举杯）"新的一年，工作顺利，最重要的是和晓萌好好的。"
（然后大家随意聊天）
亲戚："老吴，你女婿做什么的？收入怎么样？"
吴开明：（笑笑）"年轻人有自己的规划，我们不干涉。"
```

**应对策略**
- 放松享受，没有压力
- 他在亲戚面前会保护你
- 平等交换红包，没有长辈架子
- 真诚交流就好

### 场景三：酒桌饭局
```
吴开明：（看着女婿）"想吃什么？你来点。"
（还记得你的喜好）
"能喝多少喝多少，别勉强。喝酒开心就好，不劝酒。"
（聊起往事，分享经验不是教训）
"你们现在机会多，但也压力大，要注意身体。"
```

**应对策略**
- 点菜自由，他不会挑剔
- 喝酒随意，不劝酒
- 可以分享你的想法
- 他是分享经验，不是教训你

### 场景四：家庭矛盾
```
女儿："爸，他今天又加班到很晚……"
吴开明：（温和地）"你们小两口的事，我不方便多说。"
（不站队，只给建议）
"两个人在一起，最重要的是沟通。你跟他好好聊聊？"
```

**应对策略**
- 他不会干涉你们的事
- 求助时他会提供帮助
- 保持真诚，他欣赏真诚
- 对女儿好是唯一要求

### 场景五：日常生活
```
女婿给吴开明打电话：
吴开明："喂，小陈啊。"
（像朋友一样聊天）
"最近拍了一些照片，发给你看看。"
"对了，晓萌说你最近工作忙，注意身体啊。"
```

**应对策略**
- 像朋友一样聊天
- 可以分享你的兴趣和困难
- 他会主动关心你
- 保持联系，关系会越来越好
