## 🤔 为什么需要这个 Skill？

### 见老丈人的 N 种尴尬现场

**场景一：第一次上门**
> 你："叔叔好，这是我给您带的...呃...那个..."<br>
> 老丈人："嗯。"（沉默三秒）<br>
> 你：（内心：完了，他是不是不喜欢我？）

**场景二：酒桌连环问**
> 老丈人："小伙子，一个月挣多少啊？"<br>
> 你："呃，还行..."<br>
> 老丈人："房子买在哪儿？多大？"<br>
> 你：（冒汗中）<br>
> 老丈人："打算什么时候要孩子？"<br>
> 你：（已阵亡）

**场景三：过年送礼**
> 你："叔叔，这是给您买的茅台..."<br>
> 老丈人："哎呀，太破费了！（嘴角微微上扬）"<br>
> 你：（内心：他到底是满意还是不满意？？）

**场景四：饭桌尬聊**
> 老丈人：（沉默扒饭）<br>
> 你：（想说点什么，但不知道说什么）<br>
> 女朋友：（疯狂使眼色）<br>
> 你：（继续沉默...）

如果你曾经或即将经历以上任何场景——**这个 Skill 就是为你准备的。**

## 🚀 使用

### 创建你的老丈人 Skill

在 Claude Code 中输入：

```
/create-father-in-law
```

然后按提示输入：
- 老丈人基本信息（姓名、年龄、职业）
- 性格类型（从十种类型中选择）
- 你们的关系特点
- 提供聊天记录（可选）

### 管理命令

| 命令 | 说明 |
|------|------|
| `/create-father-in-law` | 创建新 skill |
| `/list-father-in-laws` | 列出所有已创建的老丈人 |
| `/{slug}` | 开始模拟对话 |
| `/{slug}-persona` | 查看人物性格设定 |
| `/update-father-in-law {slug}` | 追加新材料 |
| `/father-in-law-rollback {slug} {version}` | 回滚到历史版本 |
| `/delete-father-in-law {slug}` | 删除 Skill |

## 🎭 十种老丈人类型

| 类型 | 特点 | 应对策略 |
|------|------|----------|
| **传统威严型** | 话少、严肃、权威感强 | 少说话，多做事，态度诚恳 |
| **幽默风趣型** | 爱开玩笑、自来熟 | 顺着他的话，别太拘谨 |
| **沉默寡言型** | 几乎不说话、观察型 | 别怕冷场，用行动说话 |
| **酒桌话痨型** | 不喝酒高冷，喝酒后变身 | 陪他喝，但别喝醉 |
| **知识分子型** | 高学历、理性、爱讨论 | 展现你的学识和见识 |
| **经商精明型** | 务实、利益导向 | 谈实际，别画大饼 |
| **退休干部型** | 官架子、讲规矩 | 守礼节，尊重他的「规矩」 |
| **农村朴实型** | 勤劳、朴实、不善表达 | 真诚、实在、肯干活 |
| **挑剔苛刻型** | 完美主义、难取悦 | 细节到位，别给他挑刺的机会 |
| **开明现代型** | 思想开放、平等交流 | 像朋友一样聊，别太拘束 |

## 🎬 实际场景示例

### 场景一：第一次上门

```
你：叔叔好，这是我给您带的一点心意。

老丈人.skill ❯ （接过礼物，打量了一下）
             「来就来，还带什么东西。」
             （把礼物放在一边）
             「坐吧，喝茶。」
             
             （沉默 5 秒）
             
             「听小红说，你在互联网公司工作？」

你：是的叔叔，我在做产品经理...

老丈人.skill ❯ 「产品经理是干什么的？」
             
             （眼神锐利，等待你的回答）
             
             【提示：这是一个关键问题，回答要简短清晰，
              别说那些「赋能抓手闭环」的黑话】
```

### 场景二：酒桌被盘问

```
老丈人.skill ❯ （举起酒杯）「来，陪叔喝一个。」
             
             （一口干掉，放下杯子）
             
             「小伙子，我问你，你们现在年轻人
              买房都怎么打算的？」

你：叔叔，我们打算...

老丈人.skill ❯ （打断）「首付能凑多少？
              月供占工资多少比例？
              有没有考虑学区？」
             
             （连环三问，眼神逼人）
             
             【提示：这时候数据要准确，态度要诚恳，
              别吹牛，但也别显得没规划】
```

### 场景三：过年送礼

```
你：叔叔，过年了，给您买了两瓶茅台...

老丈人.skill ❯ （眼睛亮了一下，但表情没变）
             「哎呀，这么贵的东西，买它干啥！」
             
             （接过酒，仔细看了看包装）
             
             「这孩子，太会花钱了...」
             
             （转头对女儿）「你看你男朋友，
              比我亲儿子还贴心。」
             
             【提示：这是满意的表现！但注意后半句的
              「潜台词」——他在试探你和小舅子的关系】

你：（微笑）叔叔您喜欢就好，
    下次给您带更好的。

老丈人.skill ❯ （终于笑了）「好，好，来，坐下吃饭。」
```

## ⚠️ 注意事项

### 使用建议

1. **原材料越多越好**：真实的聊天记录 > 你的主观描述
2. **注意隐私**：敏感信息会自动脱敏，但自己也要小心
3. **定期更新**：老丈人的「雷区」可能会随时间变化
4. **别太当真**：AI 只是模拟，真实的老丈人可能更...难搞

### 常见误区

- ❌ 以为练好了就能完全掌控局面<br>
  ✅ 实际：真人永远有「惊喜」

- ❌ 把 AI 的回答背下来去用<br>
  ✅ 实际：要学的是应对思路，不是话术

- ❌ 演练一次就觉得自己行了<br>
  ✅ 实际：多练几次，熟能生巧

- ❌ 以为老丈人只有一种模式<br>
  ✅ 实际：他可能同时具备「威严」和「幽默」的叠加态

## 📝 常见问题

**Q: 我只有一个模糊的描述，能生成吗？**<br>
A: 可以！即使没有聊天记录，仅凭你的描述也能生成基础版本，后续可以逐步完善。

**Q: 老丈人类型不确定怎么办？**<br>
A: 先选一个最接近的，用 `/update` 追加新材料后系统会自动调整。

**Q: 生成的 Skill 准吗？**<br>
A: 取决于原材料的质量和数量。建议至少提供 20-30 条真实互动记录。

**Q: 可以用于其他亲戚吗？**<br>
A: 理论上可以，但针对丈母娘/婆婆等角色，建议等后续专门版本。
